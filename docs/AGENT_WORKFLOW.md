# 🤖 Система работы через AI-агентов (Antigravity / Codex)

Каждый ученик в команде работает со своим AI-агентом. Чтобы агенты не ломали чужой код, не создавали конфликты в Git и писали код в едином стиле, мы соблюдаем следующий процесс.

---

## 🔄 Цикл работы над задачей (6 шагов)

1. **Выбор задачи**:
   - Ученик открывает `task.md`, находит свою задачу со статусом `[ ]` (Todo).
   - Меняет статус на `[/]` (In Progress) и проверяет, что зависимости (если указаны) уже выполнены.
2. **Создание ветки в Git**:
   - Перед запуском агента создается отдельная ветка от актуальной ветки `dev` (см. [GIT_RULES.md](./GIT_RULES.md)).
   - Пример: `git checkout -b feat/rufina-header-theme`
3. **Постановка задачи агенту**:
   - Ученик копирует описание задачи из `task.md` и просит агента сначала прочитать `AGENTS.md` и `docs/ARCHITECTURE.md`.
   - Агент работает **только** в файлах, относящихся к этой задаче.
4. **Проверка результата (Self-Check)**:
   - Ученик (вместе с агентом) проверяет, что:
     - проект запускается без ошибок в консоли (`npm run dev`),
     - сборка проходит (`npm run build`),
     - нет хардкода секретов и небезопасных вставок `innerHTML` без `escapeHtml()`,
     - дизайн адаптивен (работает на телефоне и ПК).
5. **Обновление `task.md` и `done.md`**:
   - В `task.md` задача отмечается как `[x]`.
   - В `done.md` добавляется запись о выполненной задаче (кто делал, ветка, что именно реализовано, как проверено).
6. **Commit и Pull Request**:
   - Делается коммит по правилам Conventional Commits и открывается Pull Request в ветку `dev`.
   - **Амирхон** (архитектор) или **Ментор** проверяет PR и сливает его.

---

## 🛡 Правила безопасности при работе с агентами

1. **Один агент — одна задача — одна ветка.** Нельзя просить агента «заодно починить чужую страницу», если это не ваша задача.
2. **Не удалять чужие комментарии и файлы.**
3. **Не менять `src/core/*` и `server/db.json` без согласования с Амирхоном** (чтобы не сломать формат данных для всей команды).
4. **Понимай код, который принял.** Агент — это второй пилот, а не автопилот. Перед коммитом ученик должен уметь объяснить ментору, что делает написанный код.

## 💬 Шаблон промпта для ученика (как ставить задачу агенту)

```text
Прочитай AGENTS.md и docs/ARCHITECTURE.md.
Моя роль: <Имя>.
Моя задача из task.md: <номер и название задачи>.
Сделай только эту задачу, не трогая чужие модули.
После выполнения проверь сборку (npm run build) и подскажи, как мне протестировать результат в браузере.
```
