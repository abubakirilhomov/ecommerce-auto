# 🚗 AutoUz — Онлайн-маркетплейс автосалонов Узбекистана

Учебный коммерческий проект (E-commerce) для покупки, бронирования и продажи автомобилей от официальных и частных автосалонов Узбекистана.

Проект строится на **HTML, Tailwind CSS, DaisyUI и модульном Vanilla JS** с использованием **Vite** так, чтобы архитектура повторяла паттерны **React** (компоненты, props, централизованный state, сервисный слой API) и легко масштабировалась при переходе на React + Node.js/Express.

---

## 🎯 Бизнес-логика платформы

1. **Автосалоны (Dealers)**:
   - Регистрируются / входят в кабинет автосалона.
   - Выкладывают свои модели автомобилей (марка, модель, год, пробег, комплектация, цена в UZS/USD, фото, город).
   - Управляют своими объявлениями и видят входящие заявки на покупку / тест-драйв.
2. **Клиенты (Buyers)**:
   - Просматривают каталог автосалонов, фильтруют по марке, цене, городу (Ташкент, Самарканд, Бухара и др.), типу двигателя (бензин, электро, гибрид).
   - Изучают детальную карточку авто с галереей (Swiper.js) и характеристиками.
   - Сравнивают модели, добавляют в избранное, оформляют бронь/покупку или записываются на тест-драйв.
3. **PWA (Progressive Web App)**:
   - Приложение устанавливается на телефон/ПК, кэширует интерфейс и работает даже при нестабильном интернете.

## 🛠 Технологический стек

| Слой | Технология | Зачем используем |
| :--- | :--- | :--- |
| Сборщик | **Vite** | Быстрый dev-сервер, ES-модули, сборка продакшена |
| Разметка и стили | **HTML5 + Tailwind CSS + DaisyUI** | Быстрая и красивая верстка, готовые UI-компоненты и темы |
| Логика | **Vanilla JS (ES2022+ Modules)** | Понимание базы JS и паттернов до перехода на React |
| Анимации и слайдеры | **GSAP + Swiper.js** | Плавные переходы, скролл-эффекты и галереи автомобилей |
| Временный Backend | **json-server** | Полноценный REST API на `db.json` до перехода на Node.js + Express |
| Оффлайн и установка | **PWA (`vite-plugin-pwa` / SW)** | Манифест, иконки, кэширование |
